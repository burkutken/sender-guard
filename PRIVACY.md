# Sender Guard — Privacy Policy

_Last updated: 2026-07-15_

**Sender Guard does not collect, transmit, sell, or share any user data.** It has
no server and makes no network request to any external service.

The extension runs locally in your browser on `mail.google.com`. To analyse a
message it reads that message's headers and body using your existing Gmail
session — the same way Gmail's own "Show original" feature does. This processing
happens entirely on your device, and the results are shown only to you.

The following is stored locally in your browser (`chrome.storage.local`) and
never leaves your device:

- your extension settings;
- a small list of addresses and display names you have previously received
  verified mail from, used only for the "familiar name, new domain" warning;
- addresses you have explicitly marked as trusted.

A sender that scored as suspicious is never written to this memory.

You can erase all of it at any time from the extension's settings page
(**Data → Clear all**), or by removing the extension.

**No OAuth. No Gmail API. No analytics. No remote code.**
